# 연결·검수·추가 학습 순서

2026-10-20 기준 로컬 코드와 각 담당의 기존 기록 검토를 정리했다.
현재 학습 프로세스의 실행 상태는 이 문서로 확인할 수 없다. 이번 정리에서 학습·GPU·
체크포인트를 변경하지 않았고, 아래 항목은 새 학습 실행 승인이 아니다.

## 먼저 할 일

1. 준비된 추론 환경에서 음성/얼굴의 정확한 모델·참조·보정 자산·소스 버전을 확인한다.
   가중치·개인 미디어·환경 manifest는 private/영구 스토리지에 둔다. 공개 포트의
   factory 자리표시자를 실제 준비된 inference backend로 연결한다.
2. 얼굴을 끈 짧은 대사로 음성 원형 재현·원문 보존·청크 위치·취소·지연을 확인한다.
   그 다음 같은 대사에서 지시를 하나씩 바꿔 전달과 실제 효과를 비교한다.
3. 같은 PCM과 허용 범위의 motor를 얼굴에 전달해 픽셀 변화·주시 위치·원래 샘플 시계를
   검수한다. 생성 motor의 숫자가 모델의 물리 단위와 같다고 간주하지 않는다.
4. 동기화 허용 지연을 정한다. v30은 발화 전체를 요구하므로 현재 경로는 지연된 얼굴
   생성이다. 즉시 음성 재생과 얼굴 실시간 동기화를 동시에 보장하지 않는다.
5. 비교 결과로 실패 원인을 나눈 뒤, 코드/보정으로 해결되지 않는 항목만 학습 후보로 정한다.
   학습 전 미사용 평가 자료·성공 기준·자원/비용·이전 채택본 보존을 명시한다.

## 담당별 점검 결과

| 항목 | 추가 학습 판단 | 다음 작업/필요 자료 |
|---|---|---|
| B 음성 원형·스트리밍 연결 | 학습 필요 근거 없음 | 현재 참조 처리·실행 구성을 정확히 복원하고 어댑터 출력 동등성 확인 |
| 자연어 발성·강세 | 필요 여부 미확정 | 같은 문장·화자의 지시별 비교, 강조 위치/연결/말끝/쉼 라벨, 음색·발음·자연스러움 평가 |
| 정량 pitch/volume/speed | 현재 미지원. 학습만으로 해결된다고 확정 불가 | 조건 입력·추론 경로부터 설계. 수치 속도와 문장 내 리듬은 구분. 암묵 DSP 대체 금지 |
| 명시적 호흡 | 미지원, 학습 필요 가능성은 가설 | 대사 보존을 우선 검증. 들숨/날숨/숨 섞임 시간 라벨과 원문. 기존 자료 품질 재검수 |
| 쉼·취소·청크·재생 시계 | 학습 대상 아님 | 추가 묵음 중복·버퍼·예약 재생 시각·취소 폐기 구간을 코드로 검증 |
| 기존 얼굴·눈썹·미간 전달 | 재학습보다 연결·보정 검수가 먼저 | v30 오디오 예측과 motor 잔차를 분리 기록, 실제 이동량·보호 영역·울렁임 확인 |
| v30 온라인 전환 | 구조 변경은 필요. 재학습/증류는 후보 | 양방향 GRU·전체 발화 정규화를 causal 특징/상태로 교체할 설계. 반응 지연·유지·복귀·경계 평가 |
| 시선 위치·유지·깜박임 | 좌표 매핑에 학습은 필수 아님. 자연스러움 학습은 미확정 | 의미 대상의 물리 위치 지정, 양안 정렬 검수. focus/hold/blink는 현재 포트 미지원 |
| 기존 머리→목·어깨 연결 | 기존 동작 연결에 재학습 불필요 | 기존 추종기·관절 모델·리그를 정확히 복원하고 머리 입력과 연결 |
| 의도에 따른 독립 목·어깨 연기 | 별도 제어 규격 필요. 조건부 학습은 가설 | 의도·음성·관절 대응 자료. 일반 관절 데이터에 연기 의도 정답이 있다고 가정하지 않음 |
| 볼·턱 울렁임 | 반복 학습부터 시작할 근거 부족 | 같은 프레임에서 생성→입 합성→머리 정렬→목 연결 단계별 원인 비교 |

눈썹/미간의 ±0.025는 현재 기하 명령의 상대 변화량이지 AU 강도나 근육 수축률이
아니다. 기존 생성 예제의 0..1 motor를 그대로 이 단위에 연결하지 않는다.
범위/시선 대상 매핑이 맞지 않으면 거부하고 연결 규격부터 고친다.

## 검수 통과 기준과 역할

- **YULDION 담당:** 입력 지원/한도 검사, 요청·실제 전달·적용 보고, 실패·취소·시간축 기록.
- **음성 담당:** 원형 음색과 발음 보존, 지시별 반응, 첫 소리 지연·끊김·취소 검수.
- **얼굴 담당:** 원형 외형, 입모양, 양안 주시, 표정 반응·보호 영역·목 연결 검수.
- **공동:** 같은 짧은 대사/PCM/입력 조건으로 기준과 후보를 비교하고, 사람의 청취·시각
  검수와 기술 지표를 함께 남긴다. 샘플 위치가 맞는 것과 장치 재생이 맞는 것은 다르다.

CPU 계약 테스트 통과를 실제 배우 품질이나 모델 효과 검증으로 보고하지 않는다.
현재 채택된 추론 구성을 미채택 학습 후보와 합치거나 최신 가중치로 자동 교체하지 않는다.
